# Design briefs

Kind: briefs for the design and copy of the public website and the signed-in
application, written for a designer or a design agent to work from. A brief
describes what exists, why it exists, what must stay, what may change and
where the gains are; it is not the design itself and it changes no page.

The rules a brief works inside come from the owner and from the checks that
run on every release: the [website design standards](../guides/website-design-standards.md),
the [product style guide](../guides/product-style-guide.md), the typed site
map and layout standard the service ships, and the public-language checks of
continuous integration. When a brief and a rule disagree, the rule stands and
the brief is corrected.
