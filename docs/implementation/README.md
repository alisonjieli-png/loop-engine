# Implementation plans and execution logs

Kind: implementation plans and execution logs.

This folder holds improvement plans, backlogs, and the execution log of a
build program. A file that describes one program is dated
(`STEM-YYYY-MM-DD.md`). The current program lives in the
[roadmap](../roadmap/README.md); records here describe earlier programs
and the work they produced.

What does not belong here: verified results (see `../verification/`) and
current design (see `../architecture/`).

The [records index](../RECORDS-INDEX.md) lists every dated plan.
