# Verification reports

Kind: verification reports.

This folder holds reports of checks run at a named commit, with their
results and their limits. Every report is dated (`STEM-YYYY-MM-DD.md`)
and is a point-in-time statement: it is corrected only by a dated note
that names the correction, never rewritten. A report that finds a retired
term must quote it, so this folder is excluded from the live-language
lint.

What does not belong here: raw artifacts a report cites (see
`../evidence/`), design decisions (see `../architecture/`), and plans (see
`../roadmap/`).

The [records index](../RECORDS-INDEX.md) lists every version of each
dated report.
