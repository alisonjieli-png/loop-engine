## E. Self-repair and learning changes

| Incident | Generalized correction | Regression scope |
|---|---|---|
| Verdict for B credited A | Bind the entire evaluated subject and recorded verdict to its history digest | Genuine cross-subject verdict, mutated subject, changed plan, result ordering, duplicate members, historical v1, and valid delayed verification |
| Rejected result replaced accepted work | Separate `last_attempt` from a compact `accepted_incumbent`; preserve explicit artifact dispositions | Rejected, provisional, unbound, and errored outcomes; prior-state preservation |
| Failed or unselected output retained old trust | Invalidate overlapping string addresses from all reported outputs before selection | Failed artifact omitted from accepted refs, unselected failure, invalid index |
| Missing anchor still allowed success | Gate routing and public success on the bound acceptance of the exact emitted project | Suppressed history anchor; accepted unrelated stage after earlier project |
| Accept contradicted registered blocking gaps | Reject the contradictory response through the existing typed repair path | Blocking gaps versus nonblocking advisory findings/new requirements |
| Unicode record hashes differed | Reuse the canonical digest function; distinguish projected-result identity | Non-ASCII verifier text through the actual fixture-provider path |
| One success plus unknown rows recommended a model | Require decided outcomes per route and strict Boolean/unknown labels | Thin routes, split populations, unknown/unrouted counts, exact threshold, cost-order limits |
| Forecast summaries could override calculated loss | Reconstruct a validated base distribution and recompute scores | Overridden surprise properties, invalid subclass probability mass, zero/subnormal probabilities, unsupported labels |

State invalidation is conservative because a string address is not an
immutable artifact identity. It does not freeze filesystem bytes or detect
arbitrary unreported side effects. Accepted state still uses the current
Practitioner verifier, not an independent semantic evaluator. These limits
remain relevant to the next source-freezing and paired-control work.

## H. Distillation

`CategoricalForecastScore` provides recomputed multiclass Brier loss,
normalized Brier loss, and base-two log loss for a supplied forecast/outcome.
It does not establish that the forecast preceded the outcome, that the
evaluator is independent, or that the population is representative. The
record explicitly denies calibration, issuance, and action authority.

This is a building block for evaluating future state forecasts and low-risk
support models. No distillation dataset was qualified and no shadow model
was trained. Temporal event binding and source-cluster holdouts are still
required before predictive-quality conclusions.
