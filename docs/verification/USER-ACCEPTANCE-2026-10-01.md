## Evidence boundaries

Keep four environments separate: the dot computer, its `dev_loop` environment,
this engineering workstation, and the deployed service. Browser success on
one computer does not prove executable setup on another. A test adapter is
not the published setup. A file read is not automatic harness loading, and
automatic loading is not successful task execution.

For each attempt retain the feature, environment, release, account access
class, harness/model versions, exact component and file digests, documented
user steps, expected outcome, actual outcome, time and artifact checks. Use
passed, failed, blocked or untested. A repair creates a new attempt; preserve
the failed attempt. Redact credentials and personal data before recording
commands, configuration or logs. Never capture an expanded operator environment.
