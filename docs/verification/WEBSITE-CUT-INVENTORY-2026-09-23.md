## How to read a row

State now:

- Gone: nothing on the live site says it.
- Partly survives: some of its meaning is elsewhere; the row quotes where.
- Survives elsewhere: its meaning is on the live site in other words or
  another place; the row quotes it.
- Shown only in another state: the item exists but the served state hides it,
  for example a label that appears only when account creation opens.
- Never live: it existed only in a commit, branch or worktree that never
  reached the live site.

Decision:

- Restore as it was.
- Restore reworked: bring it back inside the redesign; the row says where.
- Superseded: the row names and quotes what replaced it.

## Against the target site map

The integrating session's target site map (header, four footer groups,
hostname surfaces) is used for placements. Six points differ from it or add
to it, each with its reason:

1. Terms of service. The target puts a link to `/terms` in the footer. The
   terms are a draft that waits for the owner, and publishing them is a legal
   commitment that needs the owner. Keep the current text "Terms of service:
   not yet published" until the owner approves the terms.
2. The repository link. Keep it out of the footer: the footer is a checked
   public surface and the repository address carries a name that must not
   appear there. Put the source link and install commands on the Docs view,
   where that name may appear (FTR-08).
3. Hostname roots. Use the uncommitted surface map (UNM-28): host
   configuration names the surface of each hostname and only the root address
   redirects to the surface's own address. The address bar then names the
   page and the page script needs no hostname test. The target's intent is
   kept.
4. demo.baltor.ai. The target points it at the homepage demonstration. Point
   it at a `/demonstration` page instead (HOST-05, UNM-25): an anchor on the
   homepage is not a page, and step S-6.37 asks for recorded demonstrations,
   each on its own subdomain.
5. Pages the target does not list: the model guidance pages (UNM-19 to
   UNM-21) and the two overnight how-to views (UNM-22, UNM-23) belong in the
   Documentation group; the suggested models draft (UNM-27) is superseded by
   the model guidance pages.
6. Get started twice. When account creation opens, the footer's access link
   turns into "Get started" beside the restored static Get started link. Make
   the Company group's invitation link static, or hide it in that state.
