## 1. Design Exemplar Research & Anti-AI-Slop Rules

We benchmarked modern minimalist personal profile and engineering showcase websites (`paco.me`, `rauno.me`, `emilkowal.ski`, `read.cv`, `karpathy.ai`) alongside open-source Anti-AI-Slop frameworks (`taste-skill`, `Nutlope/hallmark`, `pbakaus/impeccable`) and encoded 12 quantitative design dimensions (`12 x 100 = 1,200` parameterized diagnostic checks):

| Dimension ID | Quantitative Metric / Invariant | Target Band |
| :--- | :--- | :--- |
| `D01_text_per_square_inch_and_character_density` | Text Per Square Inch (`TPSI`) in reading column | `45.0 – 115.0 chars/sq.in.` |
| `D02_macro_and_micro_whitespace_ratio` | Macro Whitespace Ratio (`WSR`) & line-height (`1.62`) | `WSR >= 55%` (`0.66–0.73`) |
| `D03_directional_heading_proximity_and_vertical_rhythm` | Heading `margin-top / margin-bottom` ratio | `>= 1.8x` (`48px / 12px = 4.0x`) |
| `D04_padding_harmonic_grid_and_sibling_consistency` | `4pt / 8pt` spatial grid alignment | `100.0%` harmonic alignment |
| `D05_typography_measure_tracking_and_tabular_numerals` | Measure cap, display tracking, `tabular-nums` | `60–68ch`, `-0.028em` tracking |
| `D06_anti_ai_slop_trope_and_cliche_elimination` | Banned 3-col icon-card grids, cartoon SVGs, purple gradients | `0` AI-slop tropes allowed |
| `D07_visual_saliency_heatmap_and_clarity_score` | `16x16` 2D Saliency Heatmap & Clarity Score (`0–100`) | `Clarity >= 75.0`, `TTFF <= 320 ms` |
| `D08_warm_paper_ink_contrast_and_zero_optical_vibration` | Warm paper (`#fbfaf7`) + charcoal ink (`#161615`) | WCAG AAA without `#000/#fff` glare |
| `D09_hairline_divider_and_elevation_restraint` | `1px solid` hairline dividers (`#e6e2d8`) over drop-shadows | `>= 85%` hairline separation |
| `D10_reference_exemplar_calibration` | Cosine similarity to `paco.me`, `rauno.me`, `read.cv` | `>= 0.88` exemplar alignment |
| `D11_humanizer_voice_and_sentence_cadence` | Natural sentence variance (`humanizer-context.md`) | `sigma_L >= 5.5` words |
| `D12_public_good_accessibility_and_zero_bloat_budget` | Semantic HTML, keyboard access, instant load | `<= 80 KB` zero-dependency |
