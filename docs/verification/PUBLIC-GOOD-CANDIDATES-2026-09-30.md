for worker protection, learning and resource conservation. The coordinator
reran all 132 unit test methods successfully and confirmed the candidate
bytes did not change during those tests. These are private candidates, not
independently admitted or served library files.

## Repairs and limits

Retained failures led to fixes for oversized JSON integers, failed reads that
escaped the total I/O budget, permissive timestamp parsing and oversized
allocation certificates. The worker index now charges failed reads too and
reports actual bytes read separately from successfully indexed bytes. Consent
refusals still cause no evidence-file open. Same-family review found the
certificate bound issue; it is not independent admission.

Minimization is not anonymization. Caller-supplied dates and consent are not
authenticated facts. Source metadata checks do not fetch current law or decide
legal applicability. Caption syntax does not prove speech synchronization or
accessibility. Resource allocation makes no real-world dispatch. No real worker
data, model API call, purchase or provider mutation was used by this batch.
SDG associations describe intended uses, not measured benefit or UN endorsement.
DueCare was consulted as adjacent work, not integrated or copied.
