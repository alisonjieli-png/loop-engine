# Session context and handoffs

Kind: session orientation and handoff notes.

This folder holds the start-here files an agent reads after a new or
compacted session, the reference-source map, and dated handoff notes and
session digests (`STEM-YYYY-MM-DD.md`). Undated start-here files are kept
current; a dated handoff is a point-in-time statement from one session to
the next.

What does not belong here: current design (see `../architecture/`),
verified results (see `../verification/`), and instructions that govern
work (see `../../AGENTS.md`).

The [records index](../RECORDS-INDEX.md) lists every dated handoff.
