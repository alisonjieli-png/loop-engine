## Asset component implementation

[The original asset factory](../../tools/procedural_assets/README.md) contains
twelve constructors and 180 sizing references, split into two logical reference
groups per constructor to preserve the existing 64-file package limit. Each
reference includes its recipe, static glTF and four mesh-derived SVG views.
Shared source and repeated previews deduplicate; case count is not capability
count. These remain candidates until independent admission.

The constructors cover bears, round creatures, humanoid and quadruped proxies,
trees, boulders, houses, fences, vehicles, a water surface and a visible sun disc.
They have no rigging, animation, fur, cloth, vehicle dynamics or fluid simulation.
[Creative templates](../../tools/procedural_assets/ART-DIRECTION-TEMPLATES.md)
cover character identity, style, images, motion, slideshows and music without
claiming those instructions implement a generator.

The independent Khronos validator 2.0.0-dev.3.10 checked all 180 models with
zero errors and warnings and rejected a deliberately broken accessor. This is
format evidence, not a native-engine or aesthetic benchmark. The package checks
also execute each constructor and its tests in isolated first-party folders.
