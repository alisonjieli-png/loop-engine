# Internal development notes

This directory contains a stable maintainer-handoff pointer and historical
development notes. It does not contain a live checkout snapshot.

Current branch, dirty-file, ownership, process, task, and test facts belong in
an immutable generated `session_handoff/v1` packet. The
[handoff pointer](HANDOFF.md) explains how to use one without treating it as
architecture authority.

The earlier build prompts, migration logs, and dated handoffs belonged to the
retired repository identity. They are preserved in the pre-migration backup,
not carried into this clean repository.
