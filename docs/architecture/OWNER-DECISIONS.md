## Current clarifications, September 29, 2026

- The owner transferred responsibility for the closed OpenCode session to Codex and requested reconciliation of code, prompts, guidance, architecture, sources, components, distribution and monetization. Preserve existing component-factory work and its provenance.
- Cheap deterministic checks remain the default for generated components. Optional execution checks run when requested. Missing execution evidence means not tested, not failed or tested successfully. A model sample does not prove every package ran. Independent review, rights, secrets, permissions and effects remain separate.
- A broad private candidate collection can retain imperfect or unclassified material with findings. Candidate retention does not authorize publication or execution. Distinguish useful bytes, redistribution rights, tested consumers and observed task benefit.
- Creative and technical projects share the existing library and typed engine boundaries. The [north star](NORTH-STAR.md) defines the creative proof and preserved technical scope.
- The current hosted service is a library and account service. Browser rendering, a paired worker, hosted inference, commercial ChatGPT plan sharing and public plugin admission need an implemented and observed route before they are offered.
- Local or browser execution does not imply that no information leaves the device. Record inference, rendering, external assets and telemetry separately. Current approved privacy terms govern public behavior.
- The roadmap remains authoritative. Reconciliation changes priorities and evidence descriptions; a new design alone does not complete a task.
