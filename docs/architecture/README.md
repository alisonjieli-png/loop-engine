# Architecture records

Kind: architecture and decision records.

This folder holds the Constitution, decision records, current design
records, and dated design records. A dated record (`STEM-YYYY-MM-DD.md`)
is a point-in-time statement, and a newer date on the same stem supersedes
the older one. An undated file is a living document kept current with the
code it describes.

What does not belong here: verification reports (see `../verification/`),
research and external comparisons (see `../research/`), operating
instructions (see `../guides/`), and session handoffs (see `../context/`).

Read the [repository layout and record kinds](REPOSITORY-LAYOUT-AND-RECORD-KINDS-2026-09-18.md)
for the full charter and the [records index](../RECORDS-INDEX.md) for
every version of each dated record.
