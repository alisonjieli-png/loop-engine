# Data dictionary

The canonical rendered dictionary is
[SEMANTIC-IDENTITY-DICTIONARY.md](SEMANTIC-IDENTITY-DICTIONARY.md).

`terminology.yaml` is the machine-readable authority. This compatibility page
contains no second definitions.

The [component data dictionary](COMPONENT-DATA-DICTIONARY.md) documents the
current `LoopComponentDefinition`, `LoopValue`, atomic primitive,
`LLMWorkPacket`, and prompt-assembly fields. Its machine vocabularies live in:

- `src/loop_engine/data/component_ontology.yaml`
- `src/loop_engine/data/component_interactions.yaml`
- `src/loop_engine/data/component_folder_map.yaml`
