# Reference specifications

Kind: standing reference specifications.

This folder holds the master specification, the universal Loop standard,
the product nomenclature, and the intelligence retrieval plan. These are
undated documents revised in place, with the change recorded in the
changelog. They describe the intended shape of the system; current
behavior is defined by the Python objects in the [contract index](../contracts/README.md).

What does not belong here: dated design records (see `../architecture/`)
and operating instructions (see `../guides/`).
