# Research records

Kind: research records.

This folder holds external reading, comparisons, landscapes, and source
reviews. Every record is dated (`STEM-YYYY-MM-DD.md`). A research record
reports what was read and measured; it never claims that Loop Engine
implements a behavior. Implementation claims belong in the architecture
records, the contracts index, and the verification reports.

Dated website populations and review annotations may use the same dated stem
with a `.json` extension. They are inputs to the comparison view, not runtime
configuration or proof that an observed vendor claim is correct.

What does not belong here: decisions (see `../architecture/`), checks run
on the code (see `../verification/`), and operating instructions (see
`../guides/`).

The [records index](../RECORDS-INDEX.md) lists every version of each
dated record.
