# Baltor component research artifacts for the System Handbook

Kind: dated source map for Claude Code, September 23, 2026. The owner asked
for separate North Star, architecture, server, client, intelligence and
engine, front-end, and operations artifacts. These pages are research
companions for the handbook and Claude Code's design canvas. They are not
a parallel runtime, roadmap, approval decision or published customer claim.
The [roadmap](../roadmap/roadmap.yaml) remains the task authority and
[AGENTS.md](../../AGENTS.md) governs implementation.

| Artifact | Main question it answers | Important evidence boundary |
|---|---|---|
| [North Star](BALTOR-NORTH-STAR-ARTIFACT-2026-09-23.md) | What outcome is Baltor trying to produce, for whom, and what must be measured? | Frontier performance, overnight completion and savings are goals or hypotheses until matched task evidence exists. |
| [Architecture](BALTOR-ARCHITECTURE-ARTIFACT-2026-09-23.md) | How does the canonical Loop, a fresh harness per focused step, intelligence, typed edges and effects fit together? | Proposed engines and wrappers are distinct from deployed qualified behavior. |
| [Server side](BALTOR-SERVER-ARTIFACT-2026-09-23.md) | Which hosted authority, release, search, grants, delivery and billing paths must work at 100,000 packages? | The current single-Markdown service fails the measured synthetic 100,000-row capacity gate. |
| [Client side](BALTOR-CLIENT-ARTIFACT-2026-09-23.md) | How do Codex, Claude Code, OpenCode and Pi receive selected files, local endpoints, tools and credentials safely? | Placed, discovered, loaded, used and accepted are separate; there is no recorded invited-customer accepted step. |
| [Intelligence library and engines](BALTOR-INTELLIGENCE-AND-ENGINE-ARTIFACT-2026-09-23.md) | What counts as a distinct reviewed package, how is it generated, searched, rendered and selected? | The 80 original skill and nine mixed-format packages are candidates, not active supply. |
| [Front-end messaging, design and interface](BALTOR-FRONT-END-MESSAGING-AND-DESIGN-ARTIFACT-2026-09-23.md) | What should a visitor understand and do on desktop and phone, and which parts are live versus illustrated? | The live and in-flight draft layouts have saved visual measurements; the draft is not released. |
| [Operations and launch](BALTOR-OPERATIONS-AND-LAUNCH-ARTIFACT-2026-09-23.md) | Which release, customer, legal, payment, review and acquisition gates precede broad use? | Live health and a search/download record do not prove a complete SaaS customer journey. |

The files in this research set live in the shared checkout at
/home/username/loop-engine. Some new files are uncommitted; a separate
Git worktree does not receive those bytes automatically. Claude Code can
read these absolute paths directly from the shared machine, then bind any
adopted content to the exact reviewed commit and release. Private helper
agent messages addressed to /root are not a communication channel to
Claude Code; this index and the linked files are the handoff.
