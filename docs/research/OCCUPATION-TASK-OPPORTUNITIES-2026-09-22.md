# Pinned occupation tasks as original package opportunities

Kind: dated source and opportunity research, September 22, 2026 local
time. This report complements the
[first-party candidate factory design](FIRST-PARTY-TEN-THOUSAND-HARNESS-PACKAGES-2026-09-22.md).

was downloaded from its official site and pinned by SHA-256
`55033fc68b4c13ec23e7f74dc6378660f6e854e75d55d6e333ae0a761d3987cd`.
The [research artifact](../../artifacts/occupation-grid-research-2026-09-22/README.md)

The agency has not approved, endorsed or tested Baltor's selection or
the candidate methods that might follow from it.

The pinned ZIP contains 1,016 occupation records, 18,838 task statements
and 24,087 task-to-detailed-work-activity links. A deliberately broad
ten-occupation subset has **179 task statements and 136 distinct detailed
work activities**. Thirty-six activities appear in more than one selected
occupation. This overlap is useful for finding one reusable method that
several jobs can search for. It does not prove that every task is digital,
that it needs a harness file, or that customers will pay for it.

The [20 original method briefs](../../artifacts/occupation-grid-research-2026-09-22/next-method-briefs.md)
cite 21 task identifiers across all ten occupations. One brief uses two
occupation task IDs for the same proposed method. Each brief names
conceptual inputs, output, a discriminating known-wrong case, an
applicability facet and its nearest existing starter or new candidate.
The [identifier check](../../artifacts/occupation-grid-research-2026-09-22/check_method_briefs.py)
confirmed 20 rows and 21 real pinned references. The source inventory
check and two tests passed, including refusal of changed source bytes.
No task statement was copied into a new Agent Skill in this step.

The next production experiment should sample tasks by occupation,
activity and expected digital fit, then classify each as: already covered
by an approved method, distinct candidate need, non-digital or unsuitable,
or unknown. Record each decision and its denominator. Author original
native packages only for distinct needs with a verifiable task contract.
Use customer searches and consented project requests to change priority;
occupation prevalence alone is not demand. The first
[24-package batch](../verification/ORIGINAL-HARNESS-CANDIDATE-BATCH-QA-2026-09-22.md)
and [second batch](../verification/SECOND-ORIGINAL-HARNESS-CANDIDATE-BATCH-QA-2026-09-22.md)
are candidate supply demonstrations, not a measured conversion rate from
these 179 source tasks to approved packages.
