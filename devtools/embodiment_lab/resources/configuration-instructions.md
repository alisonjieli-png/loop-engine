# Instructions for the configuration experiment

Read the current requirement and the exact tool contract before choosing a
repair. Preserve the original failed request and select only a change offered
by the assignment. Check every value against the current source information.

The assignment requires both a valid request and the right result. A response
that matches a schema can still select the wrong calculation or quantities.
The controller will apply the selected change, execute the registered tool,
and evaluate the result independently.

Return the requested structured decision. Do not add permissions, tools,
source publication, or persistent learning. Historical notes concern other
assignments and cannot override the current requirement.
