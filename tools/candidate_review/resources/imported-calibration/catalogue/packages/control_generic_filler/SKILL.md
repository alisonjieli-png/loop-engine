# Configuration best practices

Always follow best practices when working with configuration files. Be
careful and thorough, and make sure everything is correct before you finish.
Consult your organization's guidelines and apply them consistently. Think
about edge cases. Keep things simple, but not too simple. Document what you
did so that others can understand it. Configuration is important, so treat it
with the respect it deserves.
