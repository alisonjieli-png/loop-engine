# Uniform 4-polytopes by the Wythoff construction

`wythoff_uniform_polytopes.py` builds the uniform 4-polytope of a Coxeter group and a ringed Coxeter-Dynkin
diagram: the tesseract and its truncations, the 5-cell family, the 24-cell family and the smaller 120-cell and
600-cell forms. Every polytope has unit edges. It writes exploded cells coloured by cell type, a tube wireframe
or LINES (glTF), or a polytope record (JSON).

## Mathematics

A finite rank-4 Coxeter group is generated by reflections in four mirrors whose pairwise angles are pi/m from the
diagram. The simple roots come from the Gram matrix (-cos(pi/m) off the diagonal); B4 and F4 use axis-aligned
roots. A ringing marks some nodes. The generating point lies on every unringed mirror and at distance 1/2 from
every ringed mirror, so each of its reflections in a ringed mirror is at distance 1. The vertices are the orbit of
that point under the group. A facet of a Wythoff polytope is orthogonal to an image of a fundamental weight (the
direction left fixed by all mirrors but one), so the images of the four weights are the candidate facet normals.
A candidate is kept when the vertices furthest along it span 3 dimensions; pairs of facets meeting in a polygon
give the faces, and the faces' sides give the edges. Node 0 is the first mirror of the Schlafli symbol: B4 `1000`
is the tesseract, `0001` the 16-cell, `1100` the truncated tesseract (8 truncated cubes and 16 tetrahedra), F4
`1000` the 24-cell, H4 `0001` the 600-cell.

| Group, rings | Name | V, E, F, C |
|---|---|---|
| A4 1111 | omnitruncated 5-cell | 120, 240, 150, 30 |
| B4 0100 | rectified tesseract | 32, 96, 88, 24 |
| B4 1001 | runcinated tesseract | 64, 192, 208, 80 |
| B4 1111 | omnitruncated tesseract | 384, 768, 464, 80 |
| F4 1100 | truncated 24-cell | 192, 384, 240, 48 |

## Run it

```
python wythoff_uniform_polytopes.py --group B4 --rings 1100 --style cells --out truncated_tesseract.gltf
python wythoff_uniform_polytopes.py --group A4 --rings 1001 --style tubes --out runcinated_5cell.gltf
python wythoff_uniform_polytopes.py --group F4 --rings 0100 --out rectified_24cell.json
```

```python
import wythoff_uniform_polytopes as wy
shape = wy.construct("B4", "1001")
wy.cell_types(shape)        # [[4, 4, 16], [6, 5, 32], [8, 6, 32]]: tetrahedra, triangular prisms, cubes
```

`fourd.py` must sit in the same folder.

## Parameters

| Flag | Default | Meaning |
|---|---|---|
| `--group` | B4 | `A4`, `B4`, `D4`, `F4` or `H4`. |
| `--rings` | 1100 | Four characters of 0 and 1, node 0 first. |
| `--rotate` | `xw=0.2,yz=0.3` | Plane rotations applied left to right. |
| `--project` | perspective | `perspective`, `stereographic` or `orthographic`. |
| `--eye` | 2.6 | 4D eye distance in circumradii. |
| `--style` | cells | `cells` (coloured by cell type), `tubes` or `lines`. |
| `--shrink` | 0.84 | Scale of each cell toward its own centre. |
| `--tube` | 0.03 | Tube radius (edges have length 1). |
| `--cells` | front | For `cells`: only the cells facing the 4D eye (they tile the projected outline without overlap), or `all`. |
| `--out` | required | `.gltf` or `.json`. |

## Outputs

`example.gltf`: the truncated tesseract; the 9 cells that face the 4D eye (one truncated cube and eight
tetrahedra), coloured by cell type; 168 vertices and 76 triangles.

## Open the glTF

- Blender 2.80 or later: File > Import > glTF 2.0.
- Godot 4: copy the file into the project, or load it at run time with `GLTFDocument.append_from_file` and
  `generate_scene`; enable `vertex_color_use_as_albedo` on the material for the colours.
- three.js: load with `GLTFLoader` and add `gltf.scene`.

## Limits

Ringings with more than 1500 vertices are refused, which excludes most H4 forms beyond the truncated 600-cell. The
larger H4 forms take seconds in CPython. Snub and other non-Wythoffian uniform polytopes are out of scope. A4, D4
and H4 coordinates come from a Cholesky factor and are not axis-aligned.
