## Learning across the collections

Use the axis lab to isolate a mechanism. Use whole-architecture races to test combinations. Use the canonical lab to qualify integration with actual Loop definitions, execution and stores. Use a new independently checked task population for claims about model quality or universal solving.

The following findings become qualification obligations for remixes:

| Finding | Required obligation |
|---|---|
| Shared arm memory leaked another arm's successful work | Separate initial and mutable memory per arm; record a deliberately shared-memory treatment explicitly |
| Already-green tasks taught no-op solutions | Keep already-green intake separate from verified repairs; no automatic write-back of no-op work |
| Recreated checkers accepted a tampered baseline | Preserve the original evaluator digest through copies, restarts and new checker instances |
| A void candidate was promoted | Gate/evaluator integrity and final artifact verification precede eligibility or promotion |
| A checkpoint retained a subtotal but lost its cursor | Bind state, cursor, input identity, schema/program version and relevant effect position together |
| Compaction removed an unread observation | Prove an observation was consumed or losslessly folded before deleting it |
| A folder existed without implementation | Publish status separately from discovery; unsupported execution must refuse |
| A selector collapsed meaningful string changes | Preserve semantic literals when normalizing changes; test behaviorally distinct candidates |
| Global startup code changed the evaluator | Run verification in a clean, explicitly identified environment with startup customizations excluded |
