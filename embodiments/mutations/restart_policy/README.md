# restart policy

Status: `partially_available`.

Persisted activations and history are available; complete external-effect restart qualification remains open.

For streamed work, store the accumulator with its exact cursor, input identity, schema/program version and effect position. A subtotal without its cursor must fail a reconstruction control. An in-memory dictionary that survives a function call is not a process-restart proof.

Declared arms: `new_run`, `durable_admission`, `lease_recovery`, `effect_reconciliation`.

The manifest describes the experiment; it does not grant authority or silently change a run. Preserve the population, evaluator and non-target axes. Report failed, cancelled and unavailable arms with their exact denominators. Results from the trusted deterministic backend establish mechanics only.
