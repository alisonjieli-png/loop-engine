## Issue

```text
[OWNER: greeting, or beehiiv's first-name merge field]

[OWNER: one personal opening line.]

For the past [OWNER: how long] I've been building Baltor, and today it is live at baltor.ai.

What it is
Baltor is a library for the AI agents and coding tools you already use. When your agent needs a skill, a script, a shader or a setup file for one step of a job, it searches Baltor, picks one and downloads exactly that version, with its source and licence attached.

For creative work
AgentStudios collects working files for creative projects: Godot shaders, Blender tools, procedural textures and materials, each shown with the render its check recorded. You can inspect the files and requirements before you use anything. Two small original demos are there too: Copper Current, a procedural motion loop, and First Light, a short instrumental cue, both with editable source.
Explore AgentStudios: https://agentstudios.si

For your agent's decisions
Agent Feeds gives your agent curated sources and comparison questions to read before it chooses a model, a tool or an engine. The public feeds need no account, and Agent Feeds is free through December 31, 2026.
Open AgentFeeds: https://agentfeeds.si

The whole library
More than 1.5 million harness component files: skills, subagents, commands, hooks, MCP server settings, code modules and creative files. It connects to Claude Code, Codex, OpenCode, Pi, Cursor and any app that speaks MCP. Pro is $49 a month, and Baltor never asks for your model key.
Get started: https://baltor.ai/get-started

Free for public-benefit work
Baltor Public Good offers free components for work on all 17 Sustainable Development Goals, with a free account.
Browse Public Good: https://baltor.ai/public-good

I'd love to know what you would want your agent to find there. Just reply to this email.

[OWNER: sign-off]

You are receiving this because you subscribed to [OWNER: newsletter name]. I built Baltor, so this issue is about my own product.
```
