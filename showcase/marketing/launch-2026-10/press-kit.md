### One hundred words

Baltor is a library of harness component files for AI coding agents, built
for harness and agent optimized operation. Developers keep the tool they
already run, such as Claude Code, Codex, OpenCode, Pi or Cursor, and connect
it to Baltor over MCP or a REST API. When a step needs a skill, instruction file,
tool, code module or MCP server setting, the agent searches more than 1.5
million files and downloads the exact version it chose, with its
source, licence and checksum. Agent Feeds gives agents curated sources to read
before they decide. Baltor never asks for a model key.

[100 words]

### Two hundred and fifty words

Baltor gives AI coding agents a head start. It is a library of more than 1.5
million harness component files: skills, instruction files, rules, subagents,
commands, hooks, MCP server settings, code modules, contract schemas and
creative project files. Developers keep the harness they already run, such as
Claude Code, Codex, OpenCode, Pi or Cursor, and connect it to Baltor over MCP,
a REST API or a plain feed link.

Baltor calls this harness and agent optimized operation. A harness is the
program that runs a coding agent. Instead of loading the library
into context, the agent searches short descriptions and downloads only the
component a step chose, at an exact version, with its source, licence and
SHA-256 checksum. A component that needs file, network or process access goes
only to a step that declares it.

Baltor has three offerings. Agent Feeds gives agents curated source
collections and comparison questions to read before a decision, free through
December 31, 2026. Harness Files, the Pro plan at $49 a month, opens the whole
library. Overnight / AFK Work is a free public preview of local tools for
long, bounded runs on the user's own worker.

Focused sites serve each audience: AgentFeeds for feeds, AgentFoundry for
components, AgentAFK for overnight tools and AgentStudios for creative
work such as Godot shaders, Blender tools and procedural textures. Baltor Public Good offers
free components for public-benefit work with a free account. Baltor never asks
for a model key. Baltor is operated by Baltor.AI in Saxton, Pennsylvania.

To capture the set again after a release, install the pinned browser tools
once with `npm ci --prefix showcase --ignore-scripts --no-audit --no-fund`,
then run, from the repository root:

```bash
node showcase/marketing/launch-2026-10/capture-screenshots.mjs /absolute/new/folder
```

The command refuses an existing folder, sends only GET and HEAD requests to
`baltor.ai` and `agentfeeds.si`, and fails when a page does not answer 200,
shows no heading, scrolls sideways or yields an image over 400 KB. Look at
every image before replacing the files here.
