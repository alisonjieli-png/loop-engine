    What a listing tells you

    Each row is one offering: a Model Context Protocol server you install and run, a remote endpoint you connect to, or an API built for agents. When several sources list the same offering, it is one row that names every source.

    Publisher means the listing comes from whoever owns the offering's code repository or the web address it runs at. Community means someone else listed it. Not matched means the listing does not say enough to tell.

    A sign-in shows what the listing declares. A server that declares nothing may still ask you to sign in when you connect.

    A listing is not a security review

    We have not run, tested or reviewed these servers. The registry checks that a publisher controls its namespace, a domain or a GitHub account, and that is not a security review. Read the code and the permissions of a server before you give it access to your files, accounts or keys.

    Categories come from keywords in each listing's name and description, so a row can sit in the wrong category. A licence shows only when the code host or the package registry reports one.

    Paid links

    No listing here is paid for, and no link on this page earns Baltor money. The order and the filters use only the listing facts shown on this page.

    Sources

    • Official MCP Registry. This data comes from the Official MCP Registry, read through its public interface for aggregators. Its listing data is in the public domain.
    • GitHub MCP directory, read through its public list interface.
    • Docker MCP Catalog, read from its repository, which is under the MIT License.
    • Baltor research of September 23, 2026: package licences for part of the registry.

    Other directories list MCP servers too. We link to them rather than copy them: Smithery, PulseMCP and Glama.

    Use the data

    The list is rebuilt from its sources once a day, and the date at the top says when it was last checked. Programs and agents can read it directly: the manifest names the columns, the labels and eight row files, and each row file is plain JSON.
