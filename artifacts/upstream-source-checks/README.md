# Upstream source checks

Kind: dated records of the weekly check of the upstream sources of imported items.

Each file is one run of `tools/check_upstream_sources.py`, record
`upstream_source_check/v1`: the repositories the served imported items come
from, which were read, what the host answered, and every finding with the item
identities it touches. A run without network authorization records the
inventory and reads nothing. The guide is
[catalogue feedback and withdrawal](../../docs/guides/catalogue-feedback-and-withdrawal.md).
