## Admission boundary

These rows are prompts for separately written, exact-byte reviewed Agent Skills candidates. The proposed methods need original instructions, a native-load check, source and rights review, known-wrong tests, and independent assessment against the nearest existing item. Any financial, contractual, customer-data, or external-action task must remain read-only until the host supplies explicit authority for a later effect. A useful result in one occupation does not justify cloning the same method under other occupation, employer, model, or project labels.
