# Native calibration implementation evidence

The five frozen controls are evaluation material and add zero approved or
served packages. No provider was called. Test reviewer outputs are explicitly
marked fixtures and cannot be used as real admission records.

| Evidence | Observation |
| --- | --- |
| `tests-before-implementation.txt` | The first test suite could not import the not-yet-created native calibration adapter. |
| `tests-first-implementation.txt` | Eight loader, label separation, exclusion and accounting checks passed. |
| `tests-native-cli-and-exclusion.txt` | Ten checks passed, including native command selection and actual next-phase reviewer exclusion. |
| `tests-native-final.txt` | Twelve focused tests passed, adding native call-digest and persisted exclusion controls. |
| `tests-full-component.txt` | 274 owning-component tests passed with one optional `datasketch` dependency skip. |
| `control-label-verification.json` | Five labels supported by isolated execution and exact source inspection. |

`check_removed_guards.py` writes a new dated JSON file for each run. It changes
only fixed local functions in memory and never reaches a provider. The controls
cover exact package-label binding, false-approval exclusion, native call binding,
exported reviewer exclusion, label separation and version refusal. Failed and
earlier runs stay beside their successors.

`build_controls.py` records how the fixture tree was adapted from the pinned
first-party contract-v2 scheduling package. It refuses existing destinations.
`verify_controls.py` uses the existing Bubblewrap command with no network or
host home, bounds process resources and observes the effect control only in
the private working directory. It also refuses an existing report path. The
effect control's undeclared write is deliberately invalid candidate behavior;
the trusted verifier authorizes that isolated observation solely for testing.

The [integration report](../../docs/verification/NATIVE-REVIEW-CALIBRATION-2026-09-23.md)
describes exact contracts, commands and interpretation limits. The small set
does not estimate a population false-approval rate or prove production safety.
