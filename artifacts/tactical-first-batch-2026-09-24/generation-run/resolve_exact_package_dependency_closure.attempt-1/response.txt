If the same `id` appears with a different `digest`, a `IDENTITY_COLLISION` is raised immediately.\n2. **Recursive Traversal**: For each requested package, the algorithm performs a DFS.\n3. **Cycle Detection**: A `temp_stack` (recursion stack) is maintained. If a node is encountered that is already in the current stack, a `CYCLE_DETECTED` error is raised.\n4. **Version/Digest Validation**: At every step, the dependency's `id`, `revision`, and `digest` are checked against the registry. If they don't match exactly, `DIGEST_MISMATCH` is raised.\n5. **Effect Aggregation**: Effects are collected from both the package records and the dependency links themselves.\n6. **File Aggregation**: Unique file paths are tracked to ensure `total_bytes` counts each file exactly once.\n\n## Complexity\n- **Time**: $O(P + D)$ where $P$ is the number of packages and $D$ is the number of dependency links.\n- **Space**: $O(P)$ to store the registry and visited sets.\n\n## Limitations\n- Does not perform network fetching.\n- Does not resolve semantic version ranges (requires exact matches).\n- Assumes the input JSON is valid UTF-8."
