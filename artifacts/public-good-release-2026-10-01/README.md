# Public Good collection expansion

The live collection now grants account-required, subscription-free access to
412 exact package versions containing 1,011 distinct useful files. The
existing catalogue's 30,746 rows and versions remain unchanged. Five new
Community-admitted original packages bring the full catalogue to 30,751
packages and 96,120 distinct files.

This is a catalogue and access-policy update on application release 58, not
another application deployment. The main-header `/public-good` page is live;
its individual-file browsing upgrade remains a separate source/release gate.

The corrected existing-catalogue selection supplies 996 useful files. It
reuses existing exact Community admission, with conservative access-purpose
screening and a bounded peer sample of 44 bodies in 39 packages. This is not
a new exhaustive semantic or execution certification of all selected files.
The earlier broader proposals were rejected; unrelated marketing material,
redirect-only context, install metadata and placeholder headings were excluded.

The five original packages add fifteen disjoint useful files: five programs
and ten input/output schemas. They check support-data minimization,
jurisdiction/source freshness, percentage comparisons, resource directories
and water-meter records. Their exact revised bytes passed independent
cross-family Community admission. Their supporting native wrappers, licences
and tests remain delivered, but do not pad the useful-file count.

The browser retains all seventeen goals, including empty categories. Explicit
current associations cover goals 4, 6, 8, 10 and 13, beside related public-benefit
initiatives. This does not complete all-goal coverage, prove field effectiveness,
endorse a model or establish United Nations affiliation. Free access does not
change per-file licences or fund inference and rendering.
