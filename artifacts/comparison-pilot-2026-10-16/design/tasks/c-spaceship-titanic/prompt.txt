You are working on the Kaggle Getting Started competition Spaceship Titanic. data/train.csv holds 6,970 passengers with the binary target Transported. data/test.csv holds 1,723 other passengers without the target. The columns are PassengerId (gggg_pp, where gggg is the passenger's travel group), HomePlanet, CryoSleep, Cabin (deck/num/side), Destination, Age, VIP, the amounts billed at the ship's amenities RoomService, FoodCourt, ShoppingMall, Spa and VRDeck, Name, and the target Transported.

Build a model that predicts Transported for the passengers in data/test.csv. Write a script solution.py in the project root that reads the two files, trains the model and writes predictions.csv with exactly the columns PassengerId,Transported, where Transported is True or False, and one row for every PassengerId in data/test.csv. Then run it so that predictions.csv exists.

Installing packages from the internet is not possible; use the Python packages already installed (pandas, numpy and scikit-learn). Do not submit anything to Kaggle. The labels of data/test.csv are held out and will be used to score the accuracy of predictions.csv. When you are finished, summarise your approach and the validation accuracy you measured.
